# PrivadoFile

A short description of what your software does.

## 🚀 Features

*   **Core Functionality:** Main feature description.
*   **Data Storage:** Local data persistence using structured JSON files.
*   **Activity Logging:** Complete history tracking for actions and sessions.

## 📦 Data Structure

The software securely stores data locally in the following files:
*   `storage.json` - Main software data storage.
*   `activity_log.json` - History of user actions.
*   `session_log.json` - History of software startup times.
*   `colors.py` - Color preferences.
